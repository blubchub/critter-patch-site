# Critter Patch site

Public pages for Critter Patch, a cozy pixel-art puzzle game for Apple Watch:
the [privacy policy](https://blubchub.github.io/critter-patch-site/privacy.html) and
[support](https://blubchub.github.io/critter-patch-site/support.html). Questions and bug reports go in
[Issues](https://github.com/blubchub/critter-patch-site/issues).

These files are generated from the game's source (`swift run CritterArt site docs/site`).
